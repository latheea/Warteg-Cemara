# Warteg Cemara 🍛

Website sederhana untuk warteg berbasis HTML + Tailwind CSS.

## 📌 Deskripsi
Warteg Cemara adalah website portofolio yang menampilkan:
- Menu makanan
- Pemesanan via WhatsApp
- Link ke ShopeeFood & GrabFood
- Lokasi Google Maps

## 🚀 Fitur
- Responsive (bisa di HP & laptop)
- Desain modern (Tailwind CSS)
- Tombol pesan langsung ke WhatsApp
